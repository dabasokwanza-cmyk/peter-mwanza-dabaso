# Peter Mwanza — Building a Better Dabaso

Static, GitHub Pages-ready website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main website
- `styles.css` — responsive design
- `script.js` — navigation, gallery filters/lightbox, blog search/modals, dark mode and contact form
- `assets/` — supplied photographs

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and the `assets` folder, preserving the folder structure.
3. Commit the files.
4. In GitHub: Settings → Pages → Deploy from a branch → select the main branch and `/root`.
5. Save. GitHub Pages will publish `index.html`.

## Important content note
The website organizes the campaign-supplied material as public information. Claims, experience statements and proposed priorities are presented as supplied material rather than independently verified facts.

The contact form uses `mailto:` and therefore opens the visitor's email application; it does not store form submissions on a server.

All photographs in `assets/` were supplied in the conversation and are included as local website assets.
